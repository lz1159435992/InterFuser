# RQ2 Udacity CH2

This folder contains runnable scripts/adapters for control consistency experiments (RQ2).

Key components:

- `pipeline/udacity/tools/gen_combo_dataset.py`
  - Generate enhanced CH2 combo inputs.
- `pipeline/udacity/tools/run_combo_eval.py`
  - Integrated RQ2 orchestration/evaluation entry.
- `pipeline/udacity/docker/offline-eval/`
  - Dockerized offline evaluator used in paper reruns.
- `pipeline/udacity/self-driving-car/steering-models/`
  - Steering model evaluation assets and wrappers.
