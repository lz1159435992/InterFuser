# CARLA Upstream Hosts

This directory stores selected upstream scripts and artifacts copied from host210 for RQ3 integration.

- `host210/carla_native_enhancement`: native enhancement launch/config scripts.
- `host210/results_native`: route-level result JSON artifacts.
- `host210/eval_metadata_samples`: metadata schema examples.

Use:

- `scripts/run/run_rq3_carla.sh --profile upstream-host210-native` for launcher flow.
- `scripts/run/run_rq3_carla.sh --profile upstream-host210-summary` for JSON-to-CSV extraction.
