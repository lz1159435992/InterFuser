# Reference Bundle

This folder contains a richer set of processed/sample artifacts for release packaging and quick inspection.

Included files:

- `rq1_table_rows_from_csv.tex`
- `rq1_table_rows_from_evaltex_estviol.tex`
- `rq2_violation_curve_sample.csv`
- `rq2_violation_summary_sample.csv`
- `rq3_violation_rows_sample.txt`
- `native_summary.csv`
- `rq1_summary_normalized.csv`
- `rq2_summary_normalized.csv`
- merged index files (`merged_*_index.*`)

Notes:

- Some files are historical sample outputs copied from original RQ scripts.
- `*_normalized.csv` and merged indexes are generated by scripts under `scripts/merge/`.
